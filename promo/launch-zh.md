# OpenInquire 发布文案

## 项目简介

**OpenInquire：让 Agent 用上抖音、小红书、B站和公众号里的资料。** 为四个平台提供专门的搜索与读取流程，把日常浏览器登录态、平台适配器、图文提取与视频转写、抽帧结合起来。再通过 21 个只读 MCP 工具查询 GitHub、Reddit、Hacker News、Hugging Face 等海外来源，帮你找现成方案、想选题、验证想法、查重查新。

## 社区长帖

### OpenInquire：让 Agent 查抖音、小红书、B站和公众号

抖音里的操作演示、小红书里的经验帖、B站里的长教程、公众号里的分析文章，都是调研时值得读的材料。登录后的页面、动态加载的评论、视频里的口播和画面，需要不同的读取方式。

我做了 OpenInquire，把这些平台的搜索、读取和视频处理方案整理成 Agent 可以执行的流程。浏览器复用你已有的登录状态，平台适配器提取图文与字幕，已取得的视频在后台转写、抽帧，保留来源和时间点。

读到这些材料后，还可以接着查 Reddit、Hacker News、Stack Exchange 的讨论，再到 GitHub、Hugging Face 看有没有现成实现，核对哪些说法可信、方法能不能复刻。国内外来源可以围绕同一个问题一起查。

**一个问题，原帖、评论、视频、代码一起查。** 它负责换关键词、选来源、深入材料、追踪争议，最后整理成有出处的判断与可以继续使用的资料。

它会继续读评论里的修正、视频里的操作步骤和仓库里的实现细节，将这些内容与原帖对照。视频可以在本地后台转写和抽帧，原始资料也会保留下来，后续追问时可以接着查。

为了把这些内容读进来，我整理了各个平台的具体方案：小红书和知乎复用日常浏览器登录态，B站连接专用 MCP 与笔记工具，公众号接上文章搜索与公开正文提取；海外社区、模型库、软件包和产品目录走 API 或公开订阅。遇到需要进一步理解的视频，再用 FFmpeg、离线语音转写和关键帧提取在后台处理。**把分散的接口、登录要求和内容形态，组织成一套可以执行的调研流程。** [平台与技术方案](../README.md#难接入的平台我们怎么读)

用过同类工具的人，会更容易理解它解决了哪一段工作：

- Agent Reach 把互联网渠道配好，OpenInquire 继续安排查什么、怎样核对，以及最终交付什么。
- OpenCLI 把网站变成命令，OpenInquire 把这些操作组织成围绕问题的搜索、深读与比较。
- last30days 擅长近期社区情报，OpenInquire 围绕同一主题，继续查中外平台的经验帖、历史材料、视频过程和代码实现。
- DyNote 深入抖音内容，OpenInquire 把视频里的观点带到文章、问答和代码仓库中继续验证。

**从找线索，到读懂材料，再到讲清结论，一个入口接着做。** [完整对比](../docs/comparison.md)

一个实际例子：调研某个开源工具时，问题帖里的作者先把故障归因于自己的配置，后来又更正判断、给出上游修复。OpenInquire 的评论工具读到了这三条回复，调研继续追到代码 diff，才核对清楚具体改了什么。**只看最初的帖子，就会漏掉后来的更正和修复。** [查看原始来源与过程](../examples/comments-change-the-answer.md)

仓库里有 21 个只读 MCP 工具和本地视频处理脚本：技术社区评论可以追溯，已取得的视频可以转写、抽帧并保留时间点。近期检索先交给 Agent 一份精简候选索引，完整结果留在本地；后续换问题、补材料，沿着已有资料继续查。

它可以帮你做这些事：

- **开工前先找现成的轮子。** 查清成熟方案、接入条件和真实反馈，把时间花在值得自己做的部分。
- **选题时听见真正的问题。** 看人们反复抱怨什么、现有工具遗漏什么，从材料里寻找值得验证的方向。
- **让想法有落地的起点。** 找相似实现，拆出环境、数据、步骤和验证标准，整理最小实验与复刻路线。
- **把新想法放回已有工作里比较。** 跟进论文、项目和历史讨论，列清哪些已经有人做过，差异具体在哪里。
- **把收藏变成能回看的知识。** 结合视频画面、字幕和评论，留下带时间点的笔记。
- **让写作和趋势判断有出处。** 比较不同群体的观点、近期变化与反例，整理可引用的素材和角度。

方法能不能用，也要看时间。OpenInquire 按搜索、正文、评论和媒体分别记录实测结果，运行前先试一个小样本再继续。最近一轮验收日期是 **2026-10-11**，可直接查看当时哪些路线走通、读到了哪一层。[近期实测](../docs/verification.md)

从一个念头，到查清别人做过什么，再到知道自己的下一步——把反复找资料的精力，留给选题、验证和创造。

**中外平台一起查，原帖、评论、视频、代码一起读。**
